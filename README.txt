TASKFLOW — SCHOOL PROJECT PROTOTYPE

FILES
- login.html / register.html: authentication screens
- dashboard.html: dashboard overview
- projects.html: create, search, filter, and edit projects
- project.html: tasks, progress, deadlines, project settings, demo team
- style.css: shared responsive styling
- auth.js: local demo login and registration
- app.js: shared localStorage helpers
- dashboard.js / projects.js / project.js: page functionality

HOW TO RUN
1. Extract the ZIP file into a folder.
2. Open login.html in a modern browser, or use VS Code Live Server.
3. Register an account.
4. Log in.
5. Use the sample project on the dashboard or create your own project.
6. Add tasks, set priorities and deadlines, mark tasks completed, and add simulated team usernames.

IMPORTANT LIMITATIONS
This is a front-end school-project prototype. It stores accounts and projects in localStorage in the current browser. Passwords are stored as plain text. Team members are simulated usernames, not real invitations, and different users do not share data across devices. Do not use real passwords or sensitive information. A real deployment needs a backend, password hashing, authorization, and a database.
